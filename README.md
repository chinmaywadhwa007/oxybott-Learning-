# Oxybott Studio

A modern visual programming IDE for Arduino.

![Status](https://img.shields.io/badge/status-active-success)

## Features

- Blockly Visual Programming
- Arduino C++ Code Generation
- Real Arduino CLI Compilation
- Arduino Upload
- Hardware Simulator
- Project Management
- Authentication
- SQLite Database

## Tech Stack

### Frontend
- React
- TypeScript
- Blockly
- Tailwind CSS
- Vite

### Backend
- Node.js
- Express
- SQLite
- Arduino CLI
